## 8. Instrucciones técnicas para Claude Code

> Copiar esta sección como prompt junto con el resto del documento.

**Tarea:** Construir una landing page responsive de una sola página usando la estructura, textos y datos de este documento.

**Requisitos:**
- Diseño **mobile first**, rápido y ligero.
- Stack sugerido: HTML + Tailwind CSS (o el stack que uses habitualmente), sin dependencias pesadas.
- Respetar el orden de secciones de la sección 4 y usar los textos tal cual.
- Usar la paleta de colores de la sección 3.
- Incluir botón flotante de WhatsApp, barra de llamada en móvil y menú sticky con anclas.
- Agregar meta tags, Open Graph y Schema.org de la sección 6.
- Formulario de contacto que redirija a WhatsApp con el mensaje prellenado con los datos ingresados.
- Iconos en SVG (por ejemplo Lucide) en lugar de imágenes pesadas.
- Optimizar la foto de la profesional (WebP, `loading="lazy"` donde aplique).
- Accesibilidad: atributos `alt`, contraste adecuado, botones táctiles grandes.
- Dejar los textos fáciles de editar (un solo archivo o bloque de configuración con teléfonos, nombre y textos).
